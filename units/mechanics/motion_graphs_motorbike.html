Motion Graphs — A Motorbike’s Journey

By the end of this workbook you should be able to:
  • Identify sections of a distance–time graph where an object is at rest or moving at a constant speed.
  • Match the shape of a distance–time or speed–time graph to a description of the motion it shows.
  • Calculate speed and velocity from the gradient of a distance–time graph.

1. Label the Graph

Before working with a real journey, make sure you can read what a distance–time graph is telling you at a glance. The graph below shows a motorbike’s journey — the same one you’ll use for the calculations in Section 3.

Key idea. On a distance–time graph: a flat line means the object is at rest (not moving); a straight sloped line means it’s moving at a constant speed — the steeper the line, the faster it’s going.

Glossary

Distance–time graph
A graph plotting how far an object has travelled against time. Its gradient (slope) gives the object’s speed.
Speed–time graph
A graph plotting an object’s speed against time. Its gradient gives the object’s acceleration; the area under it gives distance travelled.
Gradient
The steepness of a line on a graph, calculated as (change in the vertical value) ÷ (change in the horizontal value).
Speed
How fast an object is moving — distance travelled per unit time, with no regard to direction.
Velocity
Speed in a stated direction. On these single-direction journeys, velocity and speed have the same size.
Acceleration
The rate at which an object’s speed is changing.
Stationary
Not moving — distance (or displacement) stays constant over time.
