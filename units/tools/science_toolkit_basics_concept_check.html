Science Toolkit Basics — Concept Check

Every physics investigation leans on the same toolkit: converting between metric units, rounding sensibly, writing very large or very small numbers in scientific notation, and knowing how many digits in a measurement you can actually trust. This concept check runs through all four skills so you can find any gaps before they show up in a live experiment.

By the end of this workbook you should be able to:
  • Convert between metric prefixes without a calculator slip creeping in.
  • Round a number correctly to a stated place value.
  • Write numbers into and out of scientific (standard form) notation.
  • Apply the rules for significant figures, including rounding to a given number of sig figs.

1. Metric Prefix Conversions

Every metric prefix is just a power of ten attached to a base unit. Converting between two prefixes of the same quantity (length, mass, data, etc.) always comes down to multiplying or dividing by the ratio between their multipliers — there’s no need to look up a separate conversion factor for every possible pair.

Key idea. Converting to a smaller unit means you need more of them, so multiply. Converting to a bigger unit means you need fewer of them, so divide.

2. Rounding by Place Value

Rounding to a named place value means keeping every digit up to and including that place, then looking at the very next digit to decide whether the kept digit stays the same or rounds up.

Key idea. If the digit after the place you’re rounding to is 5 or more, round the kept digit up by one. If it’s less than 5, leave the kept digit as it is. Every digit after that point becomes a zero (for whole numbers) or is dropped (for decimals).
Place value: the value a digit represents because of its position in a number — e.g. in 392,481, the 9 is in the ten-thousands place.

3. Scientific Notation

Scientific notation (also called standard form) writes any number as a single digit from 1–9, followed by any remaining decimal digits, multiplied by a power of ten. It’s the standard way physicists write very large or very small quantities without a string of zeros.

number = a × 10n, where 1 ≤ a < 10
Key idea. Move the decimal point until exactly one non-zero digit sits before it, and count how many places it moved. Moving it left (for a large number) gives a positive power of 10; moving it right (for a small number) gives a negative power of 10.
How to type scientific notation answers: write it as coefficient × 10 to a power, using any of these — 7.25 x 10^-5, 7.25 × 10^-5, 7.25 x 10(-5), or 7.25 x 10 ^(-5). Spaces don’t matter, and x, ×, or * are all fine. Two things the checker won’t accept: leaving out the ^ or brackets between “10” and the power (7.25x10-5 reads as an entirely different expression), and calculator/programming E-notation (7.25E-5).

4. Significant Figures

The more precise a measuring tool, the more significant digits you can honestly claim in a reading. For example, of two metre sticks — one with no markings at all and one with 1000 millimetre markings — the second lets you record a measurement to more significant digits. It’s understood that the very last significant digit of any measurement is a bit uncertain — it’s always an estimate.

Rules for determining significant figures.
  1. Non-zero digits are always significant. E.g. 4627 → 4 significant figures.
  2. All final zeros after the decimal point are significant. E.g. 184.100 → 6 significant figures.
  3. Zeros between two other significant digits are always significant. E.g. 10048 → 5 significant figures.
  4. Zeros used solely to place the decimal point are not significant. E.g. 0.000479 → 3 significant figures; 479000 → 3 significant figures.
Another way to think about it: put the number in scientific notation — e.g. 0.0000436 becomes 4.36 × 10-5 — and the number of digits it takes to write the coefficient is the number of significant figures. Here it’s 3.

Glossary

Metric prefix
A word/symbol placed before a base unit to scale it by a power of ten (e.g. kilo-, milli-, mega-).
Place value
The value a digit represents because of its position within a number.
Rounding
Replacing a number with a nearby one that has fewer meaningful digits, chosen by a fixed rule (look at the next digit along).
Scientific notation (standard form)
Writing a number as a × 10n, where 1 ≤ a < 10 and n is an integer.
Significant figures (sig figs)
The digits in a measurement that carry real meaning about its precision, following the four rules in Section 4.
Precision
How finely a measuring tool or method can distinguish between close values — reflected in the number of significant figures a reading can support.
